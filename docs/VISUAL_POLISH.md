# Visual polish layer (sky, lava, fire, atmosphere, characters)

Added on branch `feature/visual-polish-ui`, 17 October 2026. Applied to all four build scenes (FirstPlayable, WeightOfPossession, FeedingFlame, NextLanding). Visual only: gameplay scripts, collisions, timings and scene layout are unchanged.

## What it adds

| Look | Asset | Where it lives in the scenes |
| --- | --- | --- |
| Infernal sky: churning smoke, molten horizon, distant fire columns | `Polish/Materials/HellSky.mat` (`HellSlice/Hell Sky` shader) | Lighting → Environment → Skybox |
| Flowing lava with glowing cracks | `Polish/Materials/Lava.mat` (`HellSlice/Lava`) | Renderers under each `SliceLava` and any object named *lava* |
| Eruption flame jets, sparks, smoke, flickering heat light | `Polish/Prefabs/FlameEruption.prefab` | Child of every `SliceHazard` → `Flames` object, so it switches on/off with the existing flame cycle |
| Drifting ash, lava embers, smoke plumes, distant wisps | `Polish/Prefabs/HellAtmosphere.prefab` | `Visual Polish (added)` root, fitted per scene |
| Bloom, ACES tonemapping, vignette, colour grading | `Polish/Prefabs/HellPostProcessing.prefab` + `Polish/HellVolumeProfile.asset` | `Visual Polish (added)` root; camera post-processing enabled |
| Protagonist model + shadow→human reveal | `Polish/Characters/BusinessMan` (A01) + `PolishSkin` + `ShadowReveal.mat` | `PolishSkin` component on the player |
| Cyclops enemy | `Polish/Characters/Cyclops` (A06, CC BY 4.0 — keep the credit) | Authored by the developer: Stage 1 guardian via `SliceEnemy.Appearance` + `Cyclops-Visual.prefab`. This tool never touches enemies |
| Warm key light, cool ambient fill, red haze fog | Lighting settings | Scene render settings |

`PolishSkin` hides the placeholder capsules and shows the model in their place; the transformation still comes from `SlicePlayer.SetReveal` (it now exposes a read-only `Reveal` value). Removing the component restores the old look.

## Re-applying (and fixing a merge conflict)

Everything is generated by **Tools → A Day Through Hell → Apply Visual Polish**. It is safe to run repeatedly: it replaces only its own `Visual Polish (added)` root, the `FlameEruption` instances and the `PolishSkin` components, and keeps asset GUIDs stable.

If a merge ever conflicts in a stage scene: keep **your** version of the scene, open the project, run **Apply Visual Polish**, check the scene, then build with **Tools → A Day Through Hell → Build Windows**.

## Requirements

- Unity **6000.3.13f1**, URP 17.3.0 (unchanged). No packages were added.
- Models: Business Man (CC0, Quaternius) and Cyclops (CC BY 4.0, DM-913) — see `ASSET_REGISTER.md` for the required Cyclops credit line.
- Performance: one shadowed directional light, unshadowed point lights only inside active flame rows, modest particle counts. Check FPS on the Intel Xe laptop at 720p with recording on.
